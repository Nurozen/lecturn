# Account appearance

When several accounts are signed in, each account has a colored glass rail around its sidebar
section. Project connectors and selected threads use the same color. Settled thread connectors
keep their red treatment, and status colors keep their usual meaning.

Account colors also decorate the conversation, settings, pull request, usage, and activity
surfaces. They do not replace the theme's text or status colors. With one account, or without
signing in, the desktop and web interface uses soft gold accents on its normal background.

Selecting a thread in another account sends a brief color wave from the selected card into the
conversation. With a single account, that effect accompanies project changes. Moving between
threads in the same project keeps the interface quiet. Messages fade between conversations once
the new conversation is ready.

The composer keeps its glass outline as it expands. Its controls move up into the expanded editor
and return to the lower strip when it rests. Your system's **Reduce Motion** preference disables
the decorative transitions.
