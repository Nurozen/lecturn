# Thread notes

Save a quote and an optional comment without adding anything to your conversation. Notes belong to a project and are available from other web or desktop clients connected to the same environment.

Select text in your own message or an assistant response, then choose **Save note**. Add a comment if useful and select **Save**. **Cite** remains a separate action that adds an assistant quote to your message draft.

Open **Notes** from the right panel's surface menu. Choose **Project** or **This thread**, and search the saved quotes and comments. Select a note to return to its message. On a narrow screen, the panel closes to reveal the message.

Saved text stays highlighted in the conversation. Click a highlight to open its note. Use **Hide highlights** in Notes to turn off this display for the current session; your saved notes remain available. **Show highlights** restores it.

Each note offers edit comment, copy, and delete actions. Deleting a note offers **Undo**. Assistant notes can also be inserted into the current chat draft as quote chips. Changing a chip's comment does not change the saved note. User-message notes cannot be inserted as assistant quotes.

In the note list, use the arrow keys, Home, and End to move between quotes, Enter to visit a source, E to edit, and Backspace to delete. Escape clears the current note selection or cancels comment editing.

If a message or thread has been removed, its saved note remains visible with an explanation. Archived threads can still be visited. Notes do not copy when you fork a thread.

Other clients receive changes when they refresh or return to the app. Notes requires an environment version that supports this feature. Native mobile capture and listing are not available yet.

## Decisions

The **Decisions** tab captures agreed choices with evidence when you enable it for a project. It uses a funded detection allowance and your thread’s connected agent. Your manually saved notes remain in **Saved**. See [Decisions](decisions.md) for setup, review and mobile behavior.
