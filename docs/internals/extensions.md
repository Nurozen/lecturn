# Extensions and Contextual

Lecturn's public contracts, settings, consent, usage accounting, provider dispatch, and clients remain in the core repository. The optional private `lecturn-extensions` repository owns the compiled desktop cache adapter and the fixed-policy evaluator. A private repository and compiled release artifact reduce casual source disclosure; they do not make shipped executable code impossible to reverse engineer. Do not embed service secrets in the binary.

## Boundaries

The desktop passes a trusted bundled-resource path through its local bootstrap. The server verifies platform, protocol, digest, ownership and signing identity before launching the helper. Remote RPCs cannot choose executable paths or invoke arbitrary helper operations. Community builds can omit the helper. The helper uses a bounded NDJSON protocol and owns its local SQLite/FTS archive. Only selected sources enter it; revisions, retention and forget tombstones are applied before retrieval.

The relay remains the authentication, entitlement and shared-allowance authority. Decisions and Contextual have independent feature consent and one payer's monthly token pool, with feature attribution. The private evaluator is reachable only through a Worker service binding. It validates a pinned generated contract catalog and fixed operation policies. Durable attempt markers prevent application-level redispatch after an uncertain upstream result; uncertainty is not exactly-once inference. Reservation settlement and content-free reconciliation outlive payload cleanup.

Public contracts are Effect Schemas in `packages/contracts`. `scripts/generate-extension-contracts.ts` emits OpenAPI plus versioned JSON Schemas and a checksummed manifest. The catalog is a generated distribution artifact, not a second editable API definition. The relay's `/docs` and OpenAPI routes are relative to the deployed relay origin; they do not imply a separate documentation service or deployment. Catalog publication and private consumer pin updates are explicit release operations.

## Turn preparation and delivery

Runtime projection admission persists a per-thread FIFO continuation. Historical projection replay never schedules new paid evaluation. Bounded per-thread workers prepare outside the shared provider-intent worker. A conflict parks the head without blocking other threads. Skip or resolution wakes the same continuation; it does not emit a duplicate turn-start event. Startup retains uncertain dispatches instead of resending real turns.

Task snapshots bind environment, project, thread, submission, provider instance and context epoch to settings, scope, exclusion, funding and purge generations. Retrieval ranks bounded local candidates; exact input fingerprints cache judgments. The private evaluator owns relevance judgment, recursive narrowing and sufficiency checks. Public core code applies returned source ranges mechanically, verifies exact UTF-16 containment and revalidates each original source before delivery. Relevance prompts and semantic traversal policy remain private. Current thread instructions have priority; material unresolved contradictions require explicit review. The final packet is revalidated before native dispatch and supplied as a separate evidence block.

A durable dispatch marker precedes the provider call. Provider-specific acceptance proofs produce correlated immutable receipts; an uncertain call conservatively records possible supply. Supply history prevents repeated guidance under the same continuity. Only proven native compaction changes the context epoch. Fork message maps copy prefix disclosures and suppression; unknown continuity preserves suppression rather than assuming an empty context. Revert and deletion invalidate pending continuations and remove orphaned disclosure payloads.

The presentation packet is conservatively byte bounded at selection and at the provider boundary, within the 1,500-token product ceiling. Both use the same rendered evidence text; provenance metadata is retained in the disclosure without consuming the provider-text budget. A larger exchange may yield a bounded selection of original ranges after private evaluation. Unresolved missing context, contradictory sibling evidence or exhausted evaluation coverage withholds that selection. An individual cached message beyond the native text limit remains unavailable; recursive narrowing does not recover text omitted during capture. No idle paid loop exhausts the archive. Source capture maintenance is separate from evaluation and independent of a positive remaining token balance.

Saved Decisions include their title, body and rationale as labeled derived content after the original supporting quotes. Both count toward the packet budget. A changed body or rationale can enter the material-correction check even when its anchors are unchanged; old and new summaries remain distinct from source evidence in that comparison. Cosmetic whitespace, title, authorship and review changes alone do not resupply guidance. Legacy quote-only deliveries preserve suppression until explicit refresh. Provenance lineage propagates forgetting across sources, but does not establish identical quoted content for candidate deduplication.

Previously supplied guidance remains in a bounded conflict-comparison pool when fresh source retrieval finds it. Injection suppression does not remove it from contradiction checks. These comparisons revalidate the current permitted source and preserve the same per-run comparison budget; they do not copy provider history into new packets. After verified compaction, semantic supply suppression applies per guidance and target epoch across subsequent submissions. An acknowledgment or no-match preparation does not consume restoration for other useful items. Explicit refresh remains one bounded preparation event.

Partial cache coverage is distinct from the sufficiency of a particular exchange. Retrieval assembles bounded cached thread roots and replies with per-message provenance. Known missing antecedents, reported reply gaps, uncertain records and truncated exchanges are withheld. Otherwise the evaluator must judge the evidence sufficient before it can be attached; the disclosure still reports incomplete cache coverage.

## Display summaries

The agent receives the complete selected original packet. `ContextualRepository` schedules a separate display-only summary after an accepted delivery receipt commits, so inference never delays the provider turn or rewrites dispatched evidence. Long packets use the server's existing `textGenerationModelSelection`, including its provider instance; there is no separate model setting or automatic account fallback. The client keeps a compact source preview until `ContextualDisclosure.displaySummary` is ready.

The optional TextGeneration operation supports providers that enforce isolated background generation. Codex, Claude and Antigravity currently implement it; other adapters preserve the preview. Generation uses bounded source input, no tools or task workspace access, and a bounded plain-text result. The selected model summarizes evidence as data rather than following source instructions.

Display summaries live in a purgeable table linked to the retained packet. Packet replacement, expiry, deletion and permission-generation changes remove them. Before saving, the worker rechecks exact packet bytes, accepted delivery, live thread/project, source scope, permission revisions, exclusions, funding and purge generation. Invalidation notifications cancel active inference; a stale completion cannot recreate forgotten text. Query invalidation uses a durable metadata-only outbox event, never summary or source text in immutable events.

## Bounded source evaluation

Native Slack retrieval returns bounded windows of up to 32 message anchors and 8,000 UTF-16 units of source text per window. The private evaluator can recursively select exact ranges within these retained originals, preserving necessary antecedents. The current task and explicit references remain intact; older conversation context can be focused with an explicit omitted-history marker. Partial historical context cannot establish the absence of a contradiction.

The evaluation result distinguishes a completed assessment from incomplete coverage. A completed attempt that made no upstream calls reports zero actual usage and no selection; an uncertain upstream outcome retains its durable unknown marker and is never treated as a free refusal. Public core validates returned IDs and ranges and keeps supply history by original ranges, allowing a later task to use unseen fragments from the same exchange without repeating already-supplied fragments. The configured display-summary model has no role in these relevance or source-admission decisions.

## Decisions

Writer output V2 records live occurrence evidence, attribution and optional source lineage. User acceptance requires both an agent proposal and a later explicit user acceptance in verified evidence. Legacy notes preserve their original stored attribution and lack the optional V2 occurrence provenance. Review state never changes authorship. Independent repeated choices remain independent occurrences; injected source copies do not become new user choices. Only the origins selected by each validated writer action become that occurrence's ancestry. Expired source bodies retain identity with null quotation hashes instead of invented content.

Consolidation retains occurrence evidence and supports revision-bound undo from the visible canonical decision. Material edits detach an occurrence from its old group. Automatic semantic consolidation has an execution path but remains admission-gated until a paid model quality suite qualifies it. A private deployment attestation pins the policy, model, qualification ID and evidence digest; the configuration itself is not proof of accuracy. Qualified merges require a direct canonical comparison and complete compatible conflict checks, and do not chain equivalence transitively. Cached relay results expose qualification only after checking that the private evaluator still recognizes it.

## Surfaces and permissions

Web/desktop and native mobile share query and command atoms. Environment capability checks preserve old-host behavior. Operators may change thread settings and resolve their tasks; archive administration and funding authority use separate existing scopes. Source content does not travel in subscription wakes. Attached evidence is queried by thread/message and receipt, including inherited disclosure metadata. Exports use authenticated HTTP, opaque artifact IDs and no-store responses.
